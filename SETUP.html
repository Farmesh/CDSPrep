🛠️ Advanced Setup Options

Option 1: Using Python (Recommended for Windows)

cd C:\path\to\CDSPREP python -m http.server 8000 # Visit http://localhost:8000 in browser

Option 2: Using Node.js

cd /path/to/CDSPREP npx http-server # Visit http://localhost:8080 in browser

Option 3: Using VS Code Live Server

  1. Install "Live Server" extension in VS Code
  2. Right-click on index.html
  3. Select "Open with Live Server"
⚠️ Note: Some features work best with a local server. If you're having issues with direct file opening, use one of the server options above.

💾 Data Storage & Privacy

✓ Privacy First

All your data (progress, quiz history, bookmarks) is stored locally in your browser using localStorage. No data is sent to any server. Your study progress is 100% private and never leaves your device.

❓ Troubleshooting

Issue: Page displays but styles look broken

Solution: Clear browser cache (Ctrl+Shift+Delete) or try a different browser

Issue: Progress not saving

Solution: Check browser settings allow localStorage. Try disabling browser extensions.

Issue: Quiz timer not working

Solution: Refresh the page. Ensure JavaScript is enabled in browser settings.

Issue: Mobile layout issues

Solution: Ensure "Desktop Mode" is enabled for better experience on tablets.
